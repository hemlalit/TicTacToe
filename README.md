# 🕹️ Tic Tac Toe Multiplayer Game (Flutter + Node.js)

A fast, fun, and real-time multiplayer Tic Tac Toe game built for Android using Flutter!  
This project showcases a complete **3-tier architecture** with real-time communication, user management, and gameplay logic — all wrapped in a sleek mobile experience.

<br/>

## 🚀 Features

- 🎮 Real-time 2-player multiplayer Tic Tac Toe
- 🔐 Room-based matchmaking (create/join with Room ID)
- ⚡ Instant game updates using **Socket.IO**
- 🏆 Score tracking and winner announcement
- 📱 Built with Flutter for a responsive and smooth mobile UI
- 💬 Scalable architecture with backend handling multiple rooms

<br/>

## 🛠️ Tech Stack

### 👨‍💻 Frontend (Client)
- **Flutter** (Dart)
- Custom UI for game board and results
- Local and remote socket event handling

### 🔗 Middle Tier (Socket Server)
- **Node.js**
- **Express.js** for server setup
- **Socket.IO** for real-time game communication

### 🗄️ Backend (Database)
- **MongoDB** for storing player details, rooms, and scores

## 📸 Gameplay Preview

- Player 1 creates a room and shares the room ID
- Player 2 joins the room using the shared ID
- Game begins — players take alternate turns
- Once a player wins or it's a draw, the result is shown
- Scores are stored and displayed at the end
